mini-social-media-api

mini-social-media-api is RESTful API built with Node.js and Express.js that allow user to create a post, update their posts and also delete their posts. It uses mysql as the database and sequelize orm, making it easy to implement relationships 

FEATURES

User can create a post

View all posts

View a particular post

Update a post

Delete a post


TECHNOLOGIES USED

Node.js
Express.js
JavaScript (common js)
Sequelize ORM
Mysql database


REQUIRMENTS

Before running the project, ensure you have installed:

Node.js (which includes npm)

Postman or another API client for testing

mysql workbench

sequelize orm

INSTALLATION AND SETUP

Clone the repository

git clone https://github.com/chizz96/mini-social-media-api.git

Navigate into the project directory:

cd mini-social-media-api

Install dependencies

npm install Or npm i

Run the project

npm run dev
